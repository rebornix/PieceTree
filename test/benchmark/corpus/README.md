# Benchmark corpus

These unmodified third-party files reproduce the corpus used by the VS Code
[Text Buffer Reimplementation](https://code.visualstudio.com/blogs/2018/03/23/text-buffer-reimplementation)
benchmarks. They are test data only and are not included in the npm package.
